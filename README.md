# Lucky Apply Support Page

This folder contains the support website for the Lucky Apply iOS app.

## Files

- `index.html` - Main support page with FAQ and contact info
- `privacy.html` - Privacy Policy page

## Publishing to GitHub Pages

To publish this to `https://skyliu.github.io/luckyapply`:

1. Create a new repository named `luckyapply` on GitHub
2. Push these files to the repository
3. Enable GitHub Pages in repository settings
4. Set source to `main` branch

## Local Testing

Open `index.html` in your browser to preview the site locally.

## Updating

To update the support page:
1. Edit the HTML files
2. Commit and push changes to GitHub
3. Changes will be live within a few minutes
